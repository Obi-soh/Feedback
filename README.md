# JAA Survey | استبيان رسامين الجزيرة

واجهة عربية RTL متجاوبة لاستبيان المجتمع الفني، بهوية مستوحاة من أرشيف رسامين الجزيرة: خلفية فحمية، أخضر زمردي، ولمسات ذهبية. يعمل المشروع كصفحة ثابتة على GitHub Pages.

## التشغيل والنشر

المشروع خالٍ من أدوات البناء. انشر محتويات المستودع عبر **Settings → Pages → Deploy from a branch → main / root**. يعتمد العرض على اتصال الإنترنت لتحميل خط Noto Sans Arabic ومكتبة Supabase الاختيارية. رابط أرشيف JAA موجود في الترويسة والصفحة.

## الاستبيان

الأسئلة محفوظة في `questions.js` ومقسمة إلى تسعة محاور. قبل البدء يحدد المشارك إن كان ضمن تجمع رسامين الجزيرة أم من خارجه. تظهر أسئلة النادي ومحور اللمة للأعضاء فقط؛ أما من خارج التجمع فتُخفى عنه، مع إبقاء سؤال «حضرت كم لمة لتجمع رسامين الجزيرة؟» متاحاً للجميع. يدعم النموذج الاختيار الواحد والمتعدد، الإجابات النصية القصيرة والطويلة، الرقم، وخياراً إضافياً عند الاقتضاء. يمكن ترك الأسئلة غير الإلزامية بلا إجابة، ويظهر سؤال عدد اللمات التفصيلي عند اختيار «حضرت قبل كدا». تُحفظ المسودة في `localStorage` على الجهاز والمتصفح الحاليين، ولا تنتقل بين الأجهزة.

## تفعيل Supabase

1. أنشئ مشروع Supabase.
2. نفّذ `supabase-setup.sql` في SQL Editor.
3. ضع Project URL ومفتاح `anon`/publishable في `supabase-config.js`. لا تضع `service_role` في الواجهة.
4. أعد النشر واختبر إرسالاً تجريبياً، ثم احذف السجل الاختباري من Supabase Studio عند الحاجة.

سياسة RLS تمنح المستخدم المجهول إنشاء مشاركة وقراءة السجلات ذات `is_public=true` فقط، ولا تمنح تحديثاً أو حذفاً. لا توجد حالياً صفحة عامة للبحث في المشاركات أو لوحة إدارة مخصصة؛ يمكن مراجعة المشاركات وتصديرها من Supabase Studio، وتتطلب الإدارة المخصصة إضافة نظام مصادقة وصلاحيات موثوقاً على الخادم. قبل فتح استقبال عام واسع، يوصى بإضافة آلية تحديد معدل الإرسال أو تحقق ضد الرسائل الآلية. لا يضمن هذا النموذج منع الإرسال المتكرر، ولا يطلب بيانات تسجيل دخول.

## ملفات المشروع

- `index.html` — صفحة التطبيق.
- `styles.css` — تنسيقات RTL المتجاوبة.
- `questions.js` — نصوص الأسئلة وخياراتها.
- `app.js` — عرض المحاور وحفظ المسودة والتحقق والإرسال الاختياري.
- `supabase-config.js` — إعدادات العميل العامة (فارغة افتراضياً).
- `supabase-setup.sql` — جدول قاعدة البيانات وسياسات RLS.

## الخصوصية والتنبيه

قبل تفعيل قاعدة البيانات، لا تُرسل الإجابات إلى أي خادم؛ تظهر بعد الإرسال رسالة صريحة بأنها بقيت محلياً. عند تفعيل Supabase، تتم كتابة `answers` كاملة للمشاركات، ولا يسمح RLS بقراءة السجل إلا إذا اختار صاحبه أن يكون عاماً. لا تتضمن هذه النسخة بعد صفحة مشاركة فردية/إحصاءات مجمعة أو لوحة إدارة، لذا فهي لا تدّعي تنفيذ هذه الوظائف.
